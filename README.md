# Omarchy Window Switcher

A native Omarchy Quattro overlay for switching between windows in the current
workspace. The plugin is under active development and is not yet submitted to
the Omarchy plugin marketplace.

The finished plugin provides three modes:

- **Icons** — a compact icon strip with one entry per window.
- **Flip** — an angled stack of window previews.
- **Grid** — an adaptive thumbnail grid and the default mode.

The switcher operates on desktop windows, not browser tabs.
